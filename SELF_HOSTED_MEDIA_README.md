# Speakathon self-hosted recordings

The website serves the 21 challenge recordings from `assets/lms/videos/day-01.mp4` through `day-21.mp4`, and their worksheets from `assets/lms/pdfs/day-01.pdf` through `day-21.pdf`.

The package also includes `day-02-solution.mp4`, `day-03-solution.mp4`, `introduction.mp4`, and `closing.mp4`. The introduction and closing videos currently use the same recording, as requested; the page presents them in separate welcome and after-Day-21 slots.

Day 12 was added from the downloaded `Challenge 12.mp4` file. All configured lesson media paths were checked against the extracted website folder. See `MEDIA_STATUS.json` for additional resource files that are named in the catalog but are not included as local files.
